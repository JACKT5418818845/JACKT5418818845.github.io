02 / 学习与技能

这门课，我这样拆成三步

HTML 负责结构与含义，CSS 负责外观与布局，JavaScript 负责行为。 下面三张卡片，就是我这一学期的主要抓手。

结构

HTML：语义化组织内容

用 header、nav、main、section、article、footer 把页面分区， 标题按 h1 → h3 逐级递进，图片补齐 alt，表单绑定 label。

  • 语义标签替代满屏 div
  • 一份标题层级，一种阅读顺序
  • 键盘与读屏也能走完全页
外观

CSS：选择器、盒模型与布局

类选择器与 id 选择器控制优先级，颜色可以继承； box-sizing 决定宽度的算法；Flexbox 排一维，Grid 排二维， 媒体查询让布局随视口变形。

  • 640px 两列，960px 三列
  • 间距用 gap，宽度用 minmax
  • 深色模式只换变量，不重写样式
行为

JavaScript：事件与 DOM

用 querySelector 找到节点，用 addEventListener 监听点击与输入， 再用 textContent、classList、setAttribute 把变化写回页面。

  • 点击按钮，文字与样式同时变
  • 表单先校验，再渲染新内容
  • 主题与留言存进 localStorage

04 / 班长日常

班长不是头衔，是接口

老师、同学、社团、教务，四边的信息在我这里汇合，再由我翻译成大家愿意看的样子。

“事情交给我，就不用再有人惦记第二遍。”

—— 我给自己定的班长标准

  • 传达与提醒

    把通知拆成“谁、什么时候、做什么”，重要节点提前一天再提醒一次。

  • 组织与协调

    班级活动先定时间地点，再分工；球赛、聚餐、志愿活动都按这个流程走。

  • 跟进与兜底

    材料收不齐就一对一问原因，有人掉队就补位，不让任何一个人掉队。
